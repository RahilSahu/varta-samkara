# SEO Audit: Varta & Samkara (static site, GitHub Pages)

Audit date: 2026-10-05. Checked generated output: index.html, posts/*/index.html (sample), videos.html, plus generate_site.py head templates.

## Where the <head> lives

Every page funnels through one shared function:

- `head(title, desc, depth, og_image="", extra_jsonld="")` at **generate_site.py:1517**. All 12 `<head>` templates in the file call this. Changing it once changes every page.
- Per-page JSON-LD builders:
  - `jsonld_article(p)` at **:1585** (article pages, template at :1970-1972)
  - `jsonld_home()` at **:1602** (homepage, template at :3123-3125)
  - `jsonld_page(name, desc, url)` at **:2492** (all `page_shell` pages, shell at :2499-2505)
  - `jsonld_scores()` at :2151, `jsonld_horoscope()` at :2187
- Pages with no JSON-LD at all: heroes.html index (:3060), archive.html (:3183), blog.html index (:3211), tags/index.html (:3424), tags/<tag>/ (:3399).

## What exists now, per page type

### Articles (posts/<slug>/, blog/<slug>/, heroes/<slug>/)
- title, meta description (truncated ~150 chars), og:title, og:description, og:image, twitter:card (summary_large_image), twitter:image, RSS link, manifest, theme script, SW register
- JSON-LD: NewsArticle or BlogPosting with headline, datePublished (date only, no time), author org "Varta & Samkara", publisher org (no logo), description, mainEntityOfPage (correct absolute URL), image

### Homepage
- Same meta set; NO og:image fallback; og:type says "article" (wrong for a homepage)
- JSON-LD: WebSite + Organization (correct URLs, Instagram sameAs)

### Videos and other page_shell pages (videos, markets, constitution, current-affairs, policy, study, study subpages, today, quiz)
- Meta only, no og:image; og:type "article" (wrong)
- JSON-LD: WebPage, but **`url` is broken**: page_shell builds it from the local `SITE` path with no slash, producing e.g. `"url": "/home/hatch/workspace/varta-samkara-websitevideos.html"` on every page_shell page. This ships a filesystem path in production JSON-LD.

### Listing pages (heroes index, archive, blog index, tags)
- Meta only, no JSON-LD, no og:image; og:type "article" (wrong)

## What is missing or wrong

1. **No canonical link on any page** (0 of 200+ pages). index.html is also served as the directory root, so Google sees two URLs for the homepage with no canonical.
2. **No og:url** on any page.
3. **og:type is hardcoded "article"** for every page; homepage and section pages should be "website".
4. **No og:image on homepage, videos, or section/listing pages**; no default fallback image. (assets/icon-512.png exists and could be a stopgap; a proper 1200x630 brand image is better.)
5. **No og:image:width/height**, no og:site_name, no og:locale, no twitter:title/twitter:description.
6. **JSON-LD url bug** in page_shell (:2500): uses `SITE` (local path) instead of `SITE_URL`.
7. **JSON-LD gaps on articles**: datePublished has no time/timezone; no dateModified; publisher has no logo; image is a plain string, not an ImageObject with dimensions; no inLanguage.
8. **Title/description lengths**: several article titles far exceed display limits (e.g. posts/2026-09-30-rosatom-nuclear title is 130 chars incl. site suffix; several at 100-118). Meta descriptions mostly fine at 150-162, but two sampled at 171 chars (trump-super-intelligence, kanpur-crash-aaib) will be cut off.
9. **No robots.txt** in the repo.
10. Listing pages have no structured data at all (could carry ItemList, optional).

## Sitemap (sitemap.xml)

- Exists and is mostly complete: 211 URLs, covering all static pages, all tags, all posts, blog posts, and heroes.
- **Missing: current-affairs.html** (generated by page_shell at :2652, active="study", but not in `sm_urls` at :3580-3587).
- feed.xml is listed in the sitemap; harmless but normally excluded.
- No `<lastmod>` on entries. A static generator can safely add file-mtime-based lastmod.

## Recommendations (static-generator only)

1. Extend `head()` with `canonical_url` and `og_type` params; emit `<link rel="canonical">`, `og:url`, `og:type`, `og:site_name`, `og:locale`, `twitter:title`, `twitter:description` everywhere.
2. Give `head()` a default og_image fallback (e.g. SITE_URL + "assets/og-default.png" at 1200x630) for pages that pass none; add og:image:width/height.
3. Fix `page_shell` url to `SITE_URL + ("" if active == "home" else active + ".html")`.
4. Article JSON-LD: add dateModified (same as datePublished at minimum), publisher logo, image as ImageObject with width/height, inLanguage "en-IN".
5. Add a length guard in the generator: truncate display title at ~60 chars before the " | Varta & Samkara" suffix, descriptions at ~155.
6. Add `current-affairs.html` to `sm_urls`; add `<lastmod>` from file mtime; drop feed.xml from sitemap.
7. Add a static robots.txt pointing at the sitemap.
8. Optional: ItemList JSON-LD on archive/blog/tags/heroes listing pages.
